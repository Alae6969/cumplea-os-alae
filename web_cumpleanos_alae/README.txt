COMO ABRIRLO EN VISUAL STUDIO CODE
----------------------------------
1. Descomprime el ZIP.
2. Abre la carpeta "web_cumpleanos_alae" en Visual Studio Code.
3. Comprueba que index.html, style.css y script.js están al mismo nivel.
4. Comprueba que existe la carpeta img.
5. Instala la extensión "Live Server".
6. Clic derecho en index.html -> Open with Live Server.

IMPORTANTE
----------
No abras solamente el index.html copiándolo a otra carpeta.
Los tres archivos deben permanecer juntos.

FOTOS
-----
Reemplaza las fotos de prueba dentro de img.
Usa los nombres:
foto1.jpg
foto2.jpg
...
foto8.jpg

Si tus fotos tienen otro formato, por ejemplo PNG:
- cambia el nombre del archivo a foto1.jpg, etc., o
- cambia .jpg por .png en index.html.

NOMBRE
------
La página ya está preparada con el nombre ALAE.

PARA CAMBIAR TEXTOS
-------------------
Todo el texto está dentro de index.html.
El diseño está en style.css.
Las animaciones y botones están en script.js.

QUE INCLUYE
